# Módulo 5 — LLM-as-a-Judge com Microsoft Copilot

Kit didático para pós-graduação em gestão em saúde. Todos os casos são **fictícios**.

## Comece aqui

1. Leia [`modulo_05_llm_as_a_judge_copilot.md`](modulo_05_llm_as_a_judge_copilot.md): roteiro completo de 50 minutos, com variante de 30 minutos.
2. Abra [`materiais/caso_ficticio_e_respostas.md`](materiais/caso_ficticio_e_respostas.md): caso, base factual e respostas A, B e C.
3. Execute os prompts no **Microsoft 365 Copilot Chat**:
   - [`materiais/prompt_juiz_absoluto.md`](materiais/prompt_juiz_absoluto.md)
   - [`materiais/prompt_juiz_comparativo.md`](materiais/prompt_juiz_comparativo.md)
4. Distribua a [`ficha de avaliação humana`](materiais/ficha_avaliacao_humana.md).
5. Ao final, consulte o [`gabarito do professor`](materiais/gabarito_professor.md).

## Observações

- Avaliar com prompts no Copilot Chat não exige funcionalidade nativa de avaliação nem Copilot Studio.
- Uma nota de LLM é um sinal imperfeito; não é certificação ou aprovação institucional.
- Verifique contas, fontes, vieses e falhas críticas com pessoas e métodos determinísticos.
- Não use dados sensíveis ou sigilosos sem autorização e controles adequados.
