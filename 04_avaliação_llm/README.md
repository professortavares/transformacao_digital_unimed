# Módulo 6 — LLM-as-a-Judge com Microsoft Copilot

Oficina em que o Copilot avalia respostas fictícias de IA com uma rubrica, e os alunos comparam essa avaliação com a de pessoas. Todos os casos são **fictícios**.

## Comece aqui

1. Leia [`01_llm_as_a_judge_copilot.md`](01_llm_as_a_judge_copilot.md): roteiro da oficina, com cronograma sugerido de 50 min.
2. Abra [`materiais/caso_ficticio_e_respostas.md`](materiais/caso_ficticio_e_respostas.md): caso, dados de referência e respostas A, B e C.
3. Antes de usar o Copilot, peça que os grupos preencham a [`ficha de avaliação humana`](materiais/ficha_avaliacao_humana.md) para as respostas A e B.
4. Execute os prompts no **Microsoft 365 Copilot Chat**:
   - [`materiais/prompt_juiz_absoluto.md`](materiais/prompt_juiz_absoluto.md)
   - [`materiais/prompt_juiz_comparativo.md`](materiais/prompt_juiz_comparativo.md)

## Observações

- Avaliar com prompts no Copilot Chat não exige funcionalidade nativa de avaliação nem Copilot Studio.
- Uma nota de LLM é um sinal imperfeito; não é certificação ou aprovação institucional.
- Verifique contas, fontes, vieses e falhas críticas com pessoas e métodos determinísticos.
- Não use dados sensíveis ou sigilosos sem autorização e controles adequados.
